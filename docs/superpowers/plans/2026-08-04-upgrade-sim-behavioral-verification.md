# Upgrade-Sim Behavioral Verification Implementation Plan

> **Status: implemented and shipped.** Historical record — its unchecked boxes are
> not open work and this plan must not be executed. See [../README.md](../README.md)
> for how the tool behaves today.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend `scripts/upgrade-sim.sh` so a simulated generator upgrade is verified
behaviorally — the same user-owned unit tests pass before and after `update`, and the
user's CLI flag remains reachable in the rebuilt binary.

**Architecture:** The sim already scaffolds a provider, injects real user logic into
every seam, fakes a v2 generator, and runs `update`. This plan adds: (a) two user-owned
Go test files written alongside that logic, (b) a baseline step that runs them and
greps the binary's `--help` for `--region` before the upgrade (abort on failure),
(c) the same checks after the upgrade (set `FAIL` on failure), and (d) one docs update.

**Tech Stack:** bash, Go tests (std `testing` only), crossplane-runtime v2
(`pkg/resource/fake`, `pkg/controller`), kingpin/v2.

**Spec:** `docs/superpowers/specs/2026-08-04-upgrade-sim-behavioral-verification-design.md`

## Global Constraints

- No new dependencies: test imports must already be in the scaffolded provider's module
  graph (crossplane-runtime v2, kingpin/v2, controller-runtime).
- No changes to `scripts/e2e-test.sh`, the Makefile, or the CLI.
- Verdict lines print explicit `✓`/`✗` via the script's `green`/`red` helpers — never
  bare `&& echo` (an absent success line is invisible).
- Baseline failure **aborts** (`exit 1`, harness is broken); post-upgrade failure sets
  the existing `FAIL=1` flag so the script exits non-zero after restoring templates.
- Test files carry the same Apache boilerplate header as the sim's other user files and
  must NOT contain "Code generated by xp-provider-gen" (that phrase marks a file
  tool-owned — the ownership-header substring trap).
- The generated module path is `github.com/example/provider-acme`; the kind package is
  `instance`, its API package `github.com/example/provider-acme/apis/compute/v1alpha1`.

## File Structure

- Modify: `scripts/upgrade-sim.sh` — all script changes (test heredocs live inside it;
  the sim is self-contained by design)
- Modify: `docs/testing.md` — upgrade-sim section, assertion list

Verification for every task is `make upgrade-sim` (~2–4 min): the sim is itself the
test harness, and its exit code plus verdict lines are the observable result.

```bash
func TestNewClientRequiresEndpoint(t *testing.T) {
	if _, err := NewClient(context.Background(), ClientConfig{}); err == nil {
		t.Fatal("NewClient with empty endpoint: want error, got nil")
	}
}

func TestNewClientBuildsFromSpecAndFlag(t *testing.T) {
	*region = "eu-central-1"
	c, err := NewClient(context.Background(), ClientConfig{
		Spec:        apisv1alpha1.ProviderConfigSpec{Endpoint: "https://api.acme.io"},
		Credentials: []byte("secret-token"),
	})
	if err != nil {
		t.Fatalf("NewClient: unexpected error: %v", err)
	}
	if c.Endpoint != "https://api.acme.io" || c.Token != "secret-token" || c.Region != "eu-central-1" {
		t.Fatalf("NewClient: unexpected client %+v", c)
	}
}

func TestFlagsParseRegion(t *testing.T) {
	app := kingpin.New("test", "")
	Flags(app)
	if _, err := app.Parse([]string{"--region=eu-west-1"}); err != nil {
		t.Fatalf("parse: %v", err)
	}
	if *region != "eu-west-1" {
		t.Fatalf("region: want eu-west-1, got %q", *region)
	}
}

func TestConfigureDoublesPollInterval(t *testing.T) {
	*region = "us-east-1"
	o := &controller.Options{PollInterval: time.Minute}
	if err := Configure(o); err != nil {
		t.Fatalf("Configure: unexpected error: %v", err)
	}
	if o.PollInterval != 2*time.Minute {
		t.Fatalf("PollInterval: want 2m0s, got %s", o.PollInterval)
	}
}

func TestConfigureRejectsEmptyRegion(t *testing.T) {
	*region = ""
	if err := Configure(&controller.Options{}); err == nil {
		t.Fatal("Configure with empty region: want error, got nil")

package instance

import (
	"context"
	"testing"
	"time"

	"github.com/crossplane/crossplane-runtime/v2/pkg/controller"
	"github.com/crossplane/crossplane-runtime/v2/pkg/resource/fake"

)

// stubManager is a non-nil ctrl.Manager whose methods are never called:
// the user's ReconcilerOptions only nil-checks it.
type stubManager struct{ ctrl.Manager }

func TestObserveNewInstanceEntersCreateFlow(t *testing.T) {
	e := NewExternal(&provider.Client{Endpoint: "https://api.acme.io", Region: "us-east-1"})
	obs, err := e.Observe(context.Background(), &v1alpha1.Instance{})
	if err != nil {
		t.Fatalf("Observe: unexpected error: %v", err)
	}
	if obs.ResourceExists {
		t.Fatal("Observe on a fresh Instance: want ResourceExists=false (create flow)")
	}
}

func TestObserveRejectsWrongKind(t *testing.T) {
	e := NewExternal(&provider.Client{})
	if _, err := e.Observe(context.Background(), &fake.Managed{}); err == nil || err.Error() != errNotInstance {
		t.Fatalf("Observe(wrong kind): want %q, got %v", errNotInstance, err)
	}
}

func TestReconcilerOptions(t *testing.T) {
	if _, err := ReconcilerOptions(nil, controller.Options{}); err == nil {
		t.Fatal("ReconcilerOptions(nil manager): want error, got nil")
	}
	opts, err := ReconcilerOptions(stubManager{}, controller.Options{PollInterval: time.Minute})
	if err != nil {
		t.Fatalf("ReconcilerOptions: unexpected error: %v", err)
	}
	if len(opts) != 1 {
		t.Fatalf("ReconcilerOptions: want 1 option, got %d", len(opts))
	}
}
EOF
```

Rationale for `fake.Managed` (do not "simplify" to `nil`): `Observe` calls
`meta.WasDeleted(mg)` **before** the type assertion, so a nil interface panics.
`fake.Managed` implements `resource.Managed` and fails the `*v1alpha1.Instance`
assertion, which is exactly the case under test.
